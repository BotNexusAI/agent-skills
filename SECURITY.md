# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability in a skill, script, workflow, or repository configuration.

Report it privately through the security contact listed on the [Veridian Labs website](https://veridianlabs.co). Include the affected path, a concise description of the impact, reproduction steps when safe to share, and any suggested mitigation.

Until the issue is resolved, do not publish exploit details, credentials, private data, or proof-of-concept payloads in a public channel.

## Skill safety

Review every skill before installing it into an agent with access to important code, credentials, or external systems. Skills are instructions and may include executable scripts; installing one is a supply-chain decision.
